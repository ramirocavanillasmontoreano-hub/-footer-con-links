# Hay jugadores

Versión visual inicial de la plataforma para conectar jugadores de fútbol 7 y fútbol 11 con equipos y contratantes.

## Incluye

- Landing page responsive con identidad verde y negra.
- Buscador visual de jugadores por nombre, posición y modalidad.
- Tarjetas de jugadores con ubicación, valoración, características y verificación.
- Modales visuales para registro y billetera.
- Secciones para jugadores, contratantes y explicación del servicio.
- Interacciones front-end sin backend: filtros, favoritos y modales.

## Ver localmente

Abrí `index.html` directamente en el navegador o publicá el repositorio con GitHub Pages.

> Esta es una versión visual. El registro real, videos, geolocalización, mensajería y pagos requieren conectar un backend y un proveedor de pagos en una siguiente etapa.
